## Результат

* **234 модуля** из прайса, разложенных по 12 подкатегориям:
  шкафы навесные (75), столы с ящиками (37), пеналы (31), столы напольные (19),
  открытые полки (18), хлебницы (16), антресоли (10), виницы (8),
  столы под мойку (8), буфеты (6), под духовой шкаф (4), торцевые (2).
* На каждый модуль: `.obj` (геометрия), `.mtl` (материалы), `.png` (миниатюра),
  `.csv` (строка прайс-спецификации). Имя файла начинается с артикула прайса.
* **42 позиции не вошли** — угловые, скошенные, радиусные, «гармошка»,
  трапеция и вогнутые фасады. Для них нужна непрямоугольная форма,
  её делают в редакторе формы PRO100. Список с ценами — `Не_вошло_в_библиотеку.csv`.

пропорции из прайса/технички сохраняются, сумма выравнивается по высоте корпуса.

## Цены: откуда что берётся

В `Прайс-спецификация_ВИСМА.csv` по каждому модулю:

* **Цена каркаса** — ровно из прайса по артикулу (например, арт. 25 = 1 900 ₽).
* **Базовый комплект** — каркас + петли (2 × арт. «Петля Боярд 90°» = 80 ₽) +
  опоры (4 × «Опора регулируемая пвх h100мм» = 25 ₽) + НПВ (650 ₽/к-т на ящик) +
  навесы (220 ₽/к-т для навесных) + ручки («Ручка скоба Бабочка 96» = 100 ₽).
* **Фасад** — справочно: площадь фасадов × цена кв.м по категории плёнки
  (кат.1 3600, кат.2 4200, кат.3 4800, кат.4 5200 ₽). Категорию и фрезеровку
  выбирает менеджер, поэтому в спецификации 4 колонки.
* **ЛДСП/ХДФ, м²** и **кромка, п.м** — из геометрии, для оценки материалов.

Проверочная сверка с прайсом: `tests/test_visma.py` (16 тестов) —
в том числе арт. 25 = 250×600×300 мм и 1 900 ₽, петли 160 ₽, цены фасадов по категориям.

## Ограничения и что уточнить

1. **Глубина.** В прайсе глубина не указана. Взяты значения технички:
   навесные 300, столы 500, пеналы 560. Для «хлебниц», «антресолей»,
   «открытых полок» и «буфетов» глубина тоже принята 300 — если у вас
   в бланке другие (например, антресоль 300 vs 280), скажите, поправлю одной строкой в `data/visma-tech.json`.
2. **Высота.** Где в названии серии нет «Н=…» (например, «Стол напольный 1-но дверный»),
   принято 720 мм для столов и 720 для навесных-без-высоты. В спецификации такие
   строки помечены в колонке «Основание размеров» — их легко найти и уточнить.
3. **Ящики.** Число и порядок высот фасадов (176/356/536) взяты из технички
   и названий серий; высота корпуса ящика — по таблице НПВ.
4. **Фурнитура сверх базовой** (ТЧО/ТПО, тандембоксы, газлифты, подъёмники,
   подсветка, GOLA) в стоимость не включена — она досчитывается отдельно по прайсу.
5. **Столешницы, стеновые панели, бортики, козырьки, багеты, пилястры,
   фрезеровки** в 3D-модель не входят: это отдельные позиции бланка заказа.

## Пересборка

```bash
python3 tools/extract_visma.py          # прайс + техничка → data/visma-modules.json
python3 -m pro100lib build-visma        # → library_visma/ (OBJ, MTL, PNG, CSV)
python3 tools/make_catalog_preview.py --library library_visma --group-by subcategory \
        --out library_visma/Каталог_ВИСМА.jpg
python3 tools/package_zip.py --src library_visma --out PRO100_Библиотека_ВИСМА.zip
```

Поменять правило (например, глубину пеналов) — `data/visma-tech.json` и
`pro100lib/visma.py`; поменять состав библиотеки (какие позиции брать) —
`tools/extract_visma.py` (список `EXCLUDE_PATTERNS`).
