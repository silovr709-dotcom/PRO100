# Детали под 3D-печать: как это работает

Модуль `partforge` строит **твердотельные параметрические модели** по размерам,
проверяет их печатаемость и отдаёт готовые STL/3MF.

## Честно о «скопировать с фото»

| Что у вас есть | Что реально получится |
|---|---|
| Чертёж / техдокументация с размерами (PDF, эскиз, скрин) | **точная модель**: размеры берутся из чертежа, геометрия строится по ним |
| Фото детали + 2–5 ключевых размеров (штангель) | **рабочая модель**: форма и посадки соблюдаются, косметика — по фото |
| Только фото, без размеров | **похожая модель**, но посадки угаданы: скорее всего потребуется 2–3 итерации |

Автоматического фотограмметрического сканирования здесь нет (это отдельные
инструменты: Polycam/RealityCapture и т. п.). Мой сильный участок — превратить
**размеры и правила в корректную печатную геометрию**: стенки, допуски, защёлки,
уклоны, отсутствие нависаний, ориентация на столе.

## Процесс

1. Вы присылаете документацию/фото/эскиз + отвечаете на 4 вопроса (ниже).
2. Я пишу JSON-спеку: тип детали + параметры в мм.
3. `python3 -m partforge build --spec spec.json --out parts_out` выдаёт:
   * `.stl` и `.3mf` — готово к слайсеру;
   * `.png` — 4 вида (изометрия, спереди, сверху, справа);
   * `.md` — карточка детали: параметры, проверка печати, рекомендации;
   * `.json` — машинный отчёт (объём, граммы, минуты, цена пластика).
4. Отчёт проверки: герметичность сетки, число тел, габариты, нависания >45°,
   пятно контакта со столом, тонкие стенки (лучом внутрь), расход и время.
5. Вы печатаете, меряете, я правлю параметры (обычно 1 итерация на допуски).

## Что нужно от вас перед началом

1. **Принтер и сопло** (например, Bambu A1 / 0.4 мм) — от этого зависят допуски.
2. **Материал** (PLA / PETG / ABS / TPU) — влияет на упругость и усадку.
3. **Как деталь работает**: что зажимает, во что вставляется, какая нагрузка.
4. **Размеры**: хотя бы габарит и посадочные diameters/расстояния между отверстиями.

## Готовые типы деталей

| Тип | Что это | Ключевые параметры |
|---|---|---|
| `led_clip` | пружинная клипса под ленту/полку | `strip_width`, `strip_height`, `screw_hole_d` |
| `hole_plug` | заглушка отверстия с грибком | `hole_d`, `clearance`, `head_d`, `depth` |
| `tolerance_coupon` | тест-купон допусков принтера | `holes`, `slots`, `pin_d` |

Новый тип — это функция в `partforge/parts.py` (получает dict параметров,
возвращает `trimesh.Trimesh`) плюс строка в `BUILDERS`.

## Первый запуск на новом принтере

Всегда печатать `tolerance_coupon`:
* отверстия 3/4/5/6/8 мм — покажут, насколько «садится» отверстие (обычно −0.15…−0.3 мм);
* пазы 0.2/0.3/0.4/0.5 мм — подберут зазор для защёлок;
* штифт и мост — покажут точность и качество моста.

По результату я подставлю `clearance` в спеку, и посадка будет с первого раза.

## Зависимости

```bash
pip install -r requirements-3d.txt
python3 -m partforge validate          # проверить все спеки
python3 -m partforge build --spec partforge/specs/led_clip.json --out parts_out
python3 -m partforge check parts_out/led_clip_10mm.stl   # проверить любой STL
```
