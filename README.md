# PRO100 — библиотека модулей (генератор)

Репозиторий собирает **полноценную библиотеку параметрических корпусных модулей**
для PRO100: модели (OBJ + MTL + PNG-текстуры), структуру папок библиотеки,
спецификацию деталей для раскроя и миниатюры модулей.

Модели импортируются в PRO100 5.20 / 6 / 7 через «Файл → Импорт → 3D модель»
и дальше сохраняются в библиотеку уже самой программой (формат `.meb`).

## Почему не генерация .meb напрямую

Формат `.meb`/`.sto` закрыт: внутри — шифротекст (энтропия 7.997 бит/байт,
нет ни открытых строк, ни сжатия zlib/bz2/lzma, ни простых XOR-обфускаций).
Подробный разбор присланного файла «для передачи.meb» и план реверса —
в [docs/meb-format-analysis.md](docs/meb-format-analysis.md).

`tools/meb_probe.py` умеет повторять этот анализ для любого `.meb`/`.sto`.

## Быстрый старт

```bash
python3 -m pro100lib list                 # список модулей
python3 -m pro100lib build                 # собрать библиотеку в library_out/
python3 tools/make_catalog_preview.py      # каталог-превью (нужен Pillow)
python3 -m pro100lib probe file.meb       # анализ .meb/.sto
```

Результат сборки:

```

├── PRO100_Библиотека_Модули/
```

## Что внутри библиотеки

| Ключ | Категория | Габариты, мм | Состав |
|---|---|---|---|
| base_400 / base_600 | Кухня/Нижние | 400/600 × 720 × 500 | корпус, полка, фасад, цоколь |
| base_800_double | Кухня/Нижние | 800 × 720 × 500 | корпус, полка, 2 фасада, цоколь |
| sink_600 | Кухня/Нижние | 600 × 720 × 500 | тумба под мойку (без полки) |
| drawers_600 | Кухня/Нижние | 600 × 720 × 500 | 3 ящика с фасадами и царгами |
| wall_400 / wall_600_double | Кухня/Верхние | 400/600 × 720 × 300 | корпус, полка, фасады |
| tall_400 | Шкафы/Пеналы | 400 × 2100 × 600 | корпус, 4 полки, фасад, цоколь |
| tall_800_double | Шкафы/Пеналы | 800 × 2200 × 600 | корпус, 4 полки, 2 фасада |
| shelving_600 | Шкафы/Стеллажи | 600 × 1800 × 400 | открытый стеллаж, 4 полки |

Толщины: ЛДСП 16 мм, ХДФ 3 мм, МДФ-фасад 18 мм, цоколь 100 мм, зазор фасадов 2 мм.

## Добавить свой модуль

```python
from pro100lib.modules import ModuleSpec, MODULES

MODULES.append(
    ModuleSpec(
        "base_900_3d", "Тумба 900 (3 фасада)", "Кухня/Нижние",
        width=900, height=720, depth=500,
        kind="base", shelves=1, doors=3, plinth=100,
    )
)
```

`kind`: `base`, `drawers`, `wall`, `tall`, `shelving`.

## Устройство кода

```
pro100lib/
├── geometry.py     # деталь-параллелепипед, UV по реальным размерам (мм на повтор)
├── materials.py    # материалы + процедурные PNG-текстуры (без бинарников в git)
├── modules.py      # параметрические модули (корпус, полки, фасады, ящики)
├── obj_export.py   # OBJ + MTL, транслитерация имён групп
├── preview.py      # изометрия в SVG (всегда) и JPG (если установлен Pillow)
├── catalog.py      # сборка дерева библиотеки, CSV-спецификации, library.json
└── cli.py          # list / build / probe
tools/meb_probe.py            # форензик .meb/.sto
tools/make_catalog_preview.py # сетка миниатюр всех модулей в один JPG
docs/meb-format-analysis.md
```

Зависимости: только стандартная библиотека Python 3.11. Pillow — опционально,
для JPG-миниатюр.
