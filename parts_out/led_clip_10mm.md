# Клипса-зажим для светодиодной ленты / полки 10 мм

Тип: `led_clip`, материал: PETG, сопло 0.4 мм, слой 0.2 мм

## Параметры

| Параметр | Значение, мм |
|---|---|
| strip_width | 10.0 |
| strip_height | 4.0 |
| wall | 1.6 |
| base_thickness | 4.0 |
| length | 16.0 |
| lip | 1.2 |
| screw_hole_d | 3.4 |
| screw_offset | 3.0 |
| clearance | 0.3 |
| countersink | True |

## Проверка печати

```
Герметичность: OK
Тел в модели: 1
Габариты: 13.4 × 16.0 × 8.3 мм
Объём: 0.933 см³, площадь поверхности: 1119.4 мм²
Нависания >45°: 18.4 % площади (нужны поддержки)
Пятно контакта со столом: 51.2 мм²  ⚠ мало, добавьте кайму/подложку
Тонких стенок (< 1.2 мм) не найдено
Печать (PETG, заполнение 30 %): ≈1.2 г, 0.39 м прутка, ≈6 мин, 2.1 ₽
```

## Что делать дальше

1. Открыть `led_clip_10mm.stl` в слайсере (Cura / PrusaSlicer / Orca).
2. Ориентация: плоской стороной на стол, как на превью «спереди».
3. Заполнение 30 %, слой 0.2 мм, поддержки — только если в отчёте есть нависания.
4. Первый раз печатать `tolerance_coupon`, чтобы подобрать зазор под свой принтер.
