# Заглушка отверстия 5 мм (мебельная, с грибком)

Тип: `hole_plug`, материал: PLA, сопло 0.4 мм, слой 0.16 мм

## Параметры

| Параметр | Значение, мм |
|---|---|
| hole_d | 5.0 |
| clearance | 0.25 |
| depth | 4.0 |
| head_d | 8.0 |
| head_h | 1.2 |
| slot | 1.0 |

## Проверка печати

```
Герметичность: OK
Тел в модели: 1
Габариты: 8.0 × 8.0 × 5.2 мм
Объём: 0.112 см³, площадь поверхности: 203.4 мм²
Нависания >45°: 18.3 % площади (нужны поддержки)
Пятно контакта со столом: 7.3 мм²  ⚠ мало, добавьте кайму/подложку
Тонких стенок (< 1.0 мм) не найдено
Печать (PLA, заполнение 20 %): ≈0.1 г, 0.05 м прутка, ≈2 мин, 0.3 ₽
```

## Что делать дальше

1. Открыть `hole_plug_5mm.stl` в слайсере (Cura / PrusaSlicer / Orca).
2. Ориентация: плоской стороной на стол, как на превью «спереди».
3. Заполнение 20 %, слой 0.16 мм, поддержки — только если в отчёте есть нависания.
4. Первый раз печатать `tolerance_coupon`, чтобы подобрать зазор под свой принтер.
